# Devlog format

One devlog per week, posted as a GitHub Discussion in the **DevLogs** category. The canonical guide is the pinned "Format Guide – Devlog" discussion (#1, Announcements). This page mirrors it.

## Title

```
Devlog | YYYY-WXX | DD–DD/MM | vX.X
```

Example: `Devlog | 2026-W08 | 23–28/02 | v0.3`

Weeks run Monday to Sunday (for example W40 is 28/09–04/10).

## Body

```
## Body

**Week Information**
- Week: 2026-WXX
- Date range: DD/MM–DD/MM
- Anomalies: (absences, delays, external constraints, or "None")

## Goals

- **Name:** what they were meant to do this week.

**Team Updates**
(Each member comments using the standard update format)
```

## Habits
- Record absences and unpushed work under Anomalies, factually and without blame.
- Goals list one bullet per person (or pair).
- Each member then posts their own update as a comment.
- If a week is missed, write it late rather than skipping it, and say so in Anomalies.
